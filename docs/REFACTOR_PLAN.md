# Refactoring plan

## Goal

Improve repository readability, consistency, and maintainability without changing numerical behavior.

## Planned work

1. Normalize repository structure for MATLAB source, tests, and documentation.
2. Add a concise repository README and repository metadata.
3. Introduce a shared ignore file for editor, MATLAB, and LaTeX artifacts.
4. Keep the LaTeX documentation tree organized under `docs/latex`.
5. Prepare a branch-based workflow for incremental refactoring and PR-based review.

## Definition of done

- Repository metadata and documentation are in place.
- Branch protection on `main` requires pull requests.
- A dedicated refactoring branch exists and is ready for follow-up work.
