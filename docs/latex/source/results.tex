\chapter{Results} \label{cha:Results}
This chapter first gives a physical interpretation of the stiffness matrix for a simplified version of
\cref{prb:Non_Normalized_Problem}. It then applies FEM to the variants in
\cref{cas:q_1st_Degree_Denom,cas:q_2nd_Degree_Denom,cas:q_Exponential} using linear and cubic basis functions and several mesh
resolutions. The resulting approximations are compared with the known analytical solutions to study convergence.
