\section{Concluding Remarks}
\begin{enumerate}
	\item The error in (\ref{eqn:FEM_Error_To_h_And_Exact_Sol}) seems to decrease quadratically with respect to the element size $h$.
	The error is also seen to depend on the exact solution through the $H^2$-Semi-Norm, i.e., through a measure of the second
	derivative of the exact solution.
	
	\item Consequently, to reduce the finite element error we have to reduce the element size and pay close attention to the regions with
	\emph{strong} solution variation.
	
	\item For other problems and/or higher dimensions the details of the error analysis follows the exact same line-out, but the
	details can be more involved.

	\item Error estimates in other norms may also be obtained by following the same approach.
\end{enumerate}
