\begin{abstract}

This report introduces \gls{FEM}, a numerical approach for solving ordinary and partial \glspl{diffEq}. We first derive and
normalize the governing equations for a one-dimensional mechanical \gls{BVP}. Before introducing FEM concepts, we also study
several problem variants that have analytical solutions.

Next, we cover the mathematical background of FEM, including variational formulations, discretization, and finite-dimensional
approximations. We also derive error estimates for a simplified version of the problem.

A finite element solution is represented by a finite linear combination of \glspl{basisFunction}. We use locally supported linear
and cubic polynomial basis functions and analyze their errors and convergence against the available analytical solutions.
\end{abstract}
